## 1. プロジェクト概要

| 項目 | 内容 |
|------|------|
| **名称** | 大阪公道シミュレーター（Osaka Koudou Simulator） |
| **形態** | Webアプリ（PWA対応・スマホ／PCブラウザ） |
| **コンセプト** | 大阪近郊の峠・公道・環状を題材に、**走行シミュレーション**と**GPSタイムアタック**を一体で楽しめるモータースポーツ向けツール |
| **タグライン** | 走る前に予測し、走ったあとに記録する——公道走行の計画〜記録を一画面で |

---

## 2. 背景・課題

### 2.1 市場・ユーザー文脈

- 大阪・近畿には信貴山（十三峠）、箕面・猿山、阪奈道路、阪神環状など、走行文化の根付いたルートが多い。
- タイム計測は専用機器や汎用GPSアプリに依存しがちで、**コース・車両・セッティングとの一体感**が弱い。
- サーキット向けシミュレーターは多いが、**大阪文脈の公道コース**に特化した無料ツールは少ない。

### 2.2 解決したい課題

| 課題 | 本アプリの解決策 |
|------|------------------|
| セッティング変更の効果が想像しづらい | 車種・パーツ・馬力を変えてラップタイムを即時計算 |
| コース形状が把握しづらい | 参照地図から抽出した走行ラインをマップ表示 |
| 現地タイムの記録・共有が面倒 | GPSゲート通過で自動計測、X・Instagram用画像で共有 |
| 複数ツールの行き来 | シミュとGPS計測を同一UI・同一コース体系で統合 |

---

## 3. ターゲットユーザー

### 3.1 ペルソナ

| 区分 | 像 | ニーズ |
|------|-----|--------|
| **メイン** | 大阪・近畿の峠／公道を走る車好き（20〜40代） | 走行前の想定ラップ、走行後のタイム記録 |
| **サブ** | チューニング・セッティング検討層 | タイヤ・軽量化・馬力変更の効果比較 |
| **サブ** | SNSで走行記録を残したい層 | タイム・コース名の共有、ストーリー用画像 |

### 3.2 利用シーン

- **走行前**: 車種・パーツを選び、想定ラップタイム・区間速度を確認
- **走行中**: スマホを固定し、GPS計測をON。ゲート通過でスタート／ゴール
- **走行後**: 記録を確認し、XやInstagramで共有
- **横画面**: スマホ横向きでタイムのみ全画面表示（計測継続）

## 4. 提供価値（3本柱）

### 4.1 セッティングシミュレーション

- 約30車種プリセット（86系、JDMスポーツ、スーパーカー等）
- パーツ：タイヤ、ブレーキ、軽量化、サス、ホイール、エアロ、デフ、吸気、冷却
- チューニング：車重（プリセット＋軽量化／任意）、目標馬力、Ne（回転上限）
- 出力：ラップタイム、区間タイム、最高速、前輪荷重、ブレーキ温度・μ、物理ログ（エビデンス付き）

### 4.2 コース可視化

- 4コースグループ × 上り／下り／周回の走行ライン
- 黒背景マップ上にコース線・ランドマーク・S/F表示
- コース／シミュ表示切替で速度色分け・ブレーキゾーン表示
- 勾配プロファイル表示

### 4.3 GPSタイムアタック

- 計測ゲート（スタート／ゴール）の**ライン通過**で自動スタート／ゴール
- スタート音・ゴール音（Web Audio）
- 記録保存（最大200件・端末内）、X・Instagramストーリー用画像共有
- 信貴山・猿山は最初のゲート通過で上り／下り自動判定

## 5. 機能一覧

### 5.1 コース

| コース | 距離目安 | 特徴 | GPS計測 |
|--------|----------|------|---------|
| **信貴山** | 約4.2km | 十三峠〜山上方面、上り／下り | 2ゲート・方向自動 |
| **猿山** | 約3.1km | 府道43・箕面方面、上り／下り | 2ゲート・方向自動 |
| **阪奈** | 上り約4.2km／下り約4.4km | 府道8号、手動で上り／下り選択 | スタート／ゴールゲート |
| **阪神環状** | 約10.3km | 外回り1周 | 周回モード（単一基点） |

コース形状は参照PNGから**赤線抽出**（`extract-red-path`）し、弧長パラメータでシミュとマップを同期。

### 5.2 GPSタイムアタック

| 機能 | 説明 |
|------|------|
| GPS ON/OFF | 専用UI（「GPS計測を開始／停止」）、状態表示・横画面HUD |
| ゲート検知 | ベクトル交差によるライン通過判定 |
| ゲート生成 | OSM道路方位から自動（`autoRoad`）、失敗時フォールバック |
| 操作 | リセット／ストップ（二重確認）、記録全削除 |
| 記録 | タイム・コース名・向き・日時（座標は記録に含めない） |
| 共有 | X intent、Instagramストーリー用画像（Canvas生成） |

### 5.3 シミュレーション

| 項目 | 内容 |
|------|------|
| 物理モデル | 出力・ギア・空力・転がり抵抗・μ・勾配・コーナ上限 |
| 根拠区分 | catalog（公称）/ calc（計算）/ extract（画像）/ config（設定） |
| 妥当帯 | GR86・sportタイヤ基準のラップ時間帯を監査スクリプトで検証 |
| エビデンス | 折りたたみパネルで数値の根拠を表示 |

### 5.4 その他

| 機能 | 説明 |
|------|------|
| 設定保存 | localStorage（車種・パーツ・コース選択等） |
| PWA | ホーム画面追加、`sw.js` による更新配信 |
| 広告 | Amazonアフィリエイト（タイヤ・装備バナー、環状族画像） |
| 監査 | 静的スクリプト（物理・ゲート・共有・仕上げ） |

## 7. 技術構成

### 7.1 アーキテクチャ

| 層 | 技術 |
|----|------|
| フロント | 単一 `index.html` + Vanilla JS + Tailwind CDN |
| 物理 | 自前積分（時間刻み・先読み制動） |
| 地図 | Canvas 2D、UV座標コース |
| GPS | Geolocation API、ベクトル交差ゲート検知 |
| ゲート | `attack-gates.js` + OpenStreetMap Overpass API |
| オフライン | Service Worker（precache + ネットワーク優先） |
| ホスティング | Vercel（本番）、GitHub（ソース） |
| ビルド | Node スクリプト（パス抽出・監査） |

**バックエンドなし** — クライアント完結、運用コスト最小化。

### 7.2 主要ファイル

| ファイル | 役割 |
|----------|------|
| `index.html` | UI・物理・シミュ・マップ描画 |
| `scripts/time-attack.js` | GPS計測・記録・共有 |
| `scripts/attack-gates.js` | コース別ゲート定義 |
| `scripts/road-gate.js` | OSM道路読み取り・ゲート生成 |
| `scripts/red-path-browser.js` | 赤線抽出（ブラウザ用） |
| `sw.js` | PWAキャッシュ |
| `scripts/*-audit.mjs` | 品質・整合性チェック |

### 7.3 開発スキルセット

- フロントエンド（HTML/CSS/JS、Canvas、PWA）
- 車両动力学（簡易モデル）
- 地図・測地（UV座標、Overpass API）
- 画像処理（赤線抽出パイプライン）
- Node.js（監査・ビルドスクリプト）

## 10. コンプライアンス・注意事項

- **道路交通法・制限速度はシミュに未適用**（娯楽・検討用途）
- GPS計測中は**画面オン推奨**（バックグラウンドでタイムずれの可能性）
- 公道走行は**法令・マナー遵守**が利用者責任
- シミュ・GPS結果は**参考値**であり実走保証ではない
- 環状族画像等の**著作権・利用許諾**は運用者が管理

---

## 11. 差別化ポイント

1. **大阪・近畿4コース特化** — ライン・ゲートを実コースに合わせて定義
2. **シミュ ⇄ GPS一体** — 同一コース体系で予測と記録を接続
3. **根拠付き物理ログ** — 公称／計算／抽出の区分で透明性
4. **PWA + 共有画像** — 走った証拠をSNSに出しやすい
5. **サーバーレス** — アカウント不要、端末内中心

## 14. リスクと対策

| リスク | 対策 |
|--------|------|
| GPS精度・ゲート取りこぼし | MIN_RACE_MS・離脱距離、OSM＋フォールバック |
| 画面オフでタイムずれ | 注意書き表示、横画面HUD |
| PWA更新が届かない | 静的sw.js、ネットワーク優先、CACHE increment |
| 著作権（画像・コース） | 利用許諾確認、参照地図は抽出ラインのみ使用 |
| 公道走行の法的問題 | 免責・注意表示、娯楽用途の明示 |

---

## 15. まとめ

**大阪公道シミュレーター**は、大阪近郊の峠・公道・環状を題材に、セッティングシミュレーションとGPSタイムアタックを一体で提供する無料Webアプリである。走る前の予測と走った後の記録・共有を一画面で支え、サーバーレス・端末内中心の設計でプライバシーと運用コストを抑えている。

**エレベーターピッチ**:  
「大阪の峠と環状を、セッティングシミュとGPSタイムで一括体験できる無料Webアプリ。走る前にラップを予測し、走ったあとにタイムを残して共有する。」
